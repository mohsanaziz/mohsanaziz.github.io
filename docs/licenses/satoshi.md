# Satoshi

`public/fonts/Satoshi.woff2` is the upright variable webfont distributed as
`Satoshi-Variable.woff2` in the official [Satoshi Fontshare package](https://www.fontshare.com/fonts/satoshi). It is downloaded by
`scripts/download-satoshi.mjs` before development and production builds, then
self-hosted with the generated site. The binary is intentionally excluded from
Git so the public source repository does not redistribute it independently.

- Retrieved: 2026-08-17
- Supported weight axis: 300–900
- SHA-256: `e739aff9b4d02c264341d6d4872edcda28e79373aeda936f659566a1cd3eb47f`

The license permits self-hosting for this website. It prohibits modifying or
subsetting the font without prior written consent from Indian Type Foundry.
